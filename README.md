# KenzCloudX

The public website of KenzCloudX, the hosted ERPNext service of Kenz Technology, as an app for a Frappe v15
bench. It serves the marketing pages in English and Arabic (right-to-left) and the demo / quote request form,
which creates ERPNext Leads.

- Pages: `/`, `/erpnext`, `/compliance`, `/zatca`, `/plans`, `/about`, `/demo`, `/privacy`, `/terms`, each
  also under `/ar/...`, plus a branded 404 page and a sitemap entry for every page.
- Demo form: `kenzcloudx.api.demo.submit_demo_request` (guest POST, rate limited to 5 per hour per IP, with a
  honeypot). It validates every field on the server, normalises international mobile numbers to `+digits`,
  and creates or updates a Lead with the custom `kcx_*` fields.
- Settings: the single DocType **KenzCloudX Settings** holds the public contact details, registration numbers,
  the two numbers shown on the site and the notification email list. Saving it clears the website cache.
- Everything the pages load (fonts, three.js r160 for the glass ribbon) is self-hosted under
  `/assets/kenzcloudx/`; there is no runtime CDN.

## Install

ERPNext is required (the form creates Leads and the fixtures add fields to Lead).

```bash
cd ~/frappe-bench
bench get-app <url-of-this-repository>
bench --site <site> install-app kenzcloudx   # erpnext must already be installed on the site
bench --site <site> migrate                  # loads the Lead custom fields and the "Website" Lead Source
```

Then fill in **KenzCloudX Settings** in the desk (contact details are hidden on the site while they are blank).

### Site config keys

| key | what it does |
| --- | --- |
| `kcx_canonical_host` | e.g. `"kenzcloudx.com"`. When set, GET/HEAD requests on an alias host get a 301 to `https://<canonical host><path>?<query>`. API, assets, files, `/app` and health checks are never redirected. Unset = off (local development). |
| `kcx_alias_hosts` | optional list (or comma-separated string) of hosts that redirect; it replaces the default. Default: `www.` and `kenzweb.` in front of the canonical host's root domain. `app.` is never a default: `app.kenzcloudx.com` is reserved for the customer portal on this site (a 301 is cached by browsers). |
| `host_name` | e.g. `"https://kenzcloudx.com"`, so the sitemap and email links use the public address. |

Deploy (production site only, after the domains are added in Press):

```bash
bench --site <site> set-config kcx_canonical_host kenzcloudx.com
# optional, only to change the default list (www.kenzcloudx.com, kenzweb.kenzcloudx.com):
bench --site <site> set-config --parse kcx_alias_hosts '["www.kenzcloudx.com", "kenzweb.kenzcloudx.com"]'
bench --site <site> set-config host_name https://kenzcloudx.com
```

Every alias host must also be added to the site as a domain (and get a certificate), otherwise the request
never reaches the site.

## Where things are

| what | where |
| --- | --- |
| Page text, English and Arabic | `kenzcloudx/website/content/en.json`, `ar.json` (same structure; a test checks parity) |
| Page templates | `kenzcloudx/templates/kenz/` (shared chrome) and `templates/kenz/pages/` (page bodies) |
| Routes | `kenzcloudx/www/` and `kenzcloudx/www/ar/` |
| Page context (language, settings, canonical, hreflang) | `kenzcloudx/website/context.py` |
| Styles and scripts | `kenzcloudx/public/css/kenz.css`, `kenzcloudx/public/js/` |
| Demo form API | `kenzcloudx/api/demo.py` |
| Canonical-host redirect | `kenzcloudx/redirects.py` |
| Social images (`og-en.png`, `og-ar.png`) | generated by `scripts/og/render.mjs` (see the file header) |

All copy lives in the content JSON: change text there, in both languages, and restart the web workers
(content is read once per process). Templates escape every value; keep `|e` on every `{{ }}` (a test checks it).

## Tests

```bash
bench --site <test-site> set-config allow_tests true
bench --site <test-site> run-tests --app kenzcloudx
```

**Never run the tests on a production site.** Some tests commit (HTTP requests through the real app, Error
Log checks), change KenzCloudX Settings for a moment and clear the website cache. Use a local or staging
site with ERPNext installed.
